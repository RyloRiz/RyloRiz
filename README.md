## 🔭 Recently built

- 🔌 **PortBar** - a macOS menu bar app that shows live listening TCP ports with process name/PID and one-click (tree-)kill, so you stop typing `lsof -i :3000` and `pgrep`/`pkill` fifteen times a day. Built for OpenAI Build Week using Codex/GPT-5.6.
- 🌊 **Flow** - a Git-compatible CLI that swaps commits/branches for three plain concepts: **Work**, **History**, **Publish**. Git still runs underneath - your repo, GitHub, and tooling don't know the difference.
- 🛡️ **Bouncer** - a sandboxed wrapper (`bouncer "<command>"`) for running commands you don't fully trust, with approval prompts for filesystem writes, network calls, and privilege escalation.
- 🎓 **Sidequest** - a UCLA-scoped micro-internship marketplace, built as a team project on Next.js, Prisma/PostgreSQL, and Better-Auth.
- 💻 **rizwaan.dev** - A cinematic Three.js **scrollytelling portfolio** w/ scroll-driven 3D scenes, GSAP/Lenis camera choreography, physically-based materials.
- A few iOS apps: a QR scanner, better Insta layout maker, etc.
